# AnyTrack Editor v0.12.8

Кроссплатформенный редактор и конструктор спортивных маршрутов для файлов
FIT, GPX и TCX. Работает на Windows, macOS и Linux, поддерживает русский и
английский интерфейс.

## Возможности

- загрузка нескольких тренировок и сравнение их на одной карте;
- редактирование треков, удаление фрагментов, Undo/Redo;
- отдельные и объединённые графики скорости, пульса, каденса, мощности и высоты;
- поиск GPS-аномалий, телепортаций и недопустимой спортивной скорости;
- экспорт результата в GPX и TCX с сохранением доступных данных;
- создание маршрутов для ходьбы, бега, велосипеда, MTB и сплава по реке;
- облачная маршрутизация GraphHopper либо собственный локальный сервер;
- автоматическая загрузка региональных карт OpenStreetMap для офлайн-маршрутов;
- сохранение созданного маршрута как GPX без искусственных времени и скорости;
- светлая и тёмная темы.

## Запуск

Откройте папку своей операционной системы и запустите соответствующий файл:

- Windows — `Windows/start_windows.bat`;
- macOS — `macOS/start_macos.command`;
- Linux — `Linux/start_linux.sh`.

Нужен Python 3.11–3.13. При первом запуске сценарий создаст отдельное
виртуальное окружение и установит зависимости. Подробные инструкции находятся
в README-файле внутри каждой системной папки.

## Структура

- `Program` — исходный код, зависимости и общая документация;
- `Windows` — запуск и сборка для Windows;
- `macOS` — запуск и сборка для macOS;
- `Linux` — запуск и сборка для Linux.

## Локальный GraphHopper

Откройте настройки и выберите «Локальный GraphHopper». Мастер последовательно
установит компоненты, скачает выбранный регион OpenStreetMap и подготовит базу.
После подготовки маршруты по этому региону можно строить без интернета.
