ANYTRACK EDITOR 0.12.8 — WINDOWS

1. Install 64-bit Python 3.11, 3.12 or 3.13 from python.org.
   During installation enable "Add Python to PATH".
2. Run start_windows.bat.
3. The first launch downloads dependencies and may take several minutes.
   Later launches use the local Windows\.venv folder.

To make a portable Windows application, run build_windows_exe.bat on Windows.
The result appears in Windows\dist\AnyTrack Editor\.

Do not move the Windows folder away from the neighboring Program folder.

Optional local routing is installed from Settings. GraphHopper, portable Java
and the selected OpenStreetMap region are stored separately from the program.
